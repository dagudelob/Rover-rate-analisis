# Workspace Guidelines

- **Language Policy**: Always generate all code, comments, docstrings, log messages, commit messages, and variable/function names in **English**.
- **Git Branching Policy**: Never make edits or commit directly to the `main` branch. Always create a dedicated branch (`feature/`, `fix/`, `refactor/`) for any task, push it to `origin`, and prepare a Pull Request description using `.github/PULL_REQUEST_TEMPLATE.md`.
